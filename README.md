# Numbernaut (Pygame)

A Pygame remake of the original Godot Numbernaut game. Match the number on
each cloud to bounce safely and keep climbing; mismatched clouds reduce your
number. The run ends when it reaches zero. The game renders on a 6x pixel-art
canvas to preserve the original 100x160 coordinate system while allowing
fractional movement between game pixels.

## Run

```bash
python -m pip install -r requirements.txt
python main.py
```

Click **PLAY** or press Enter/Space to start. Move with the left/right arrow
keys or A/D. Press Escape to quit.

The original sprite sheets, font, and sound effects are in `assets/`.
